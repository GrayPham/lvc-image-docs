**API Server** turns the tool into an image-generation server. Other programs (Python scripts, websites, n8n, Make…) send HTTP requests in and get images back. The images are generated with the accounts already in the tool.

<TutorialVideo id="api-server" />

## Start the server

<Steps>

1. In the left sidebar, click **🔌 API Server**.

2. **1 · MÁY CHỦ** (Server): leave **Nghe ở** (Listen on) as *Chỉ máy này (127.0.0.1)* (This machine only), **Cổng** (Port) 5199, **Luồng** (Threads) 2.

3. **2 · KHOÁ API** (API key): click <kbd>Tạo khoá mới</kbd> (Create new key). Click <kbd>📋</kbd> to copy the key.

4. **3 · MẶC ĐỊNH** (Defaults): choose the model, aspect ratio and image save folder to use when a request doesn't specify them.

5. Click <kbd>▶ Bật máy chủ</kbd> (Start server). Wait until the status shows **🟢 Đang chạy — sẵn sàng nhận lệnh** (Running — ready for requests).

</Steps>

Tick **Tự bật khi mở tool** (Start when the tool opens) if this machine is your permanent image server. Since version 1.1.61, the tool remembers the key and all settings after you close and reopen it.

On the right of the tab are <kbd>Chép lệnh curl</kbd> (Copy curl command) and <kbd>Chép mã Python</kbd> (Copy Python code) buttons, already filled in with your address and key.

<Aside type="danger" title="Keep your API key secret">
Anyone with the key can generate images with your accounts, which means spending your credits. Never put the key in public source code.

If you choose *Mở ra mạng ngoài (0.0.0.0)* (Open to external network), other machines on your network, and even the Internet if your router forwards the port, can call in. In that case the key must be at least 24 characters long. Use a key generated by the tool.
</Aside>

## Authentication

Every request except `/v1/health` must include the key in one of two ways:

```http
Authorization: Bearer <key>
X-API-Key: <key>
```

## Endpoints

| Method | Path | What it does |
| --- | --- | --- |
| `GET` | `/v1/health` | Server status. No key needed. |
| `GET` | `/v1/models` | List of models, aspect ratios, upscale options. |
| `POST` | `/v1/images` | Generate images (text → image, or image → image). |
| `GET` | `/v1/images/<id>` | Check progress and results. |
| `GET` | `/v1/images/<id>/file/<n>` | Download image file number n. |
| `DELETE` | `/v1/images/<id>` | Delete the job and its images. |

Default base URL: `http://127.0.0.1:5199`.

## Generate images: `POST /v1/images`

| Field | Type | Meaning |
| --- | --- | --- |
| `prompt` | string | **Required.** The image description. |
| `so_luong` | number | Number of images, 1–8. Default 1. |
| `model` | string | `banana2`, `bananapro`, `bananalite`, `imagen4`, `muse`, `chatgpt`. Defaults to the tab setting. |
| `ty_le` | string | `1:1`, `9:16`, `16:9`. Defaults to the tab setting. |
| `upscale` | string | Leave empty for no upscale; `2K` or `4K`. Only `banana2`, `bananapro`, `bananalite`. |
| `anh_tham_chieu` | array | Reference images as base64 or data URIs, up to 3. All models except `imagen4`. |
| `cho` | true/false | `true`: wait until done before returning. `false` (default): return an `id` immediately and check progress later. |
| `han_giay` | number | Maximum wait time when `cho: true`. Default 300, range 10–900 seconds. |

The `banana2`, `bananapro`, `bananalite` and `imagen4` models use the enabled Google Flow accounts. `muse` uses Muse AI accounts, `chatgpt` uses ChatGPT accounts.

### Example

<Tabs>
<TabItem label="Python">

```python
import base64, requests

GOC  = "http://127.0.0.1:5199"
KHOA = "<key>"
H    = {"Authorization": "Bearer " + KHOA}

# Text -> image, wait until done, then return
r = requests.post(GOC + "/v1/images", headers=H, json={
    "prompt": "a golden retriever astronaut on Mars",
    "so_luong": 1, "model": "banana2", "ty_le": "1:1",
    "upscale": "4K", "cho": True,
}, timeout=600).json()
print(r["trang_thai"], r.get("loi", ""))

# Download the images
for a in r["anh"]:
    with open("anh_%d.png" % a["chi_so"], "wb") as f:
        f.write(requests.get(a["url"], headers=H).content)

# Image -> image: send reference images (up to 3)
ref = base64.b64encode(open("mau.png", "rb").read()).decode()
r2 = requests.post(GOC + "/v1/images", headers=H, json={
    "prompt": "same character, snowy forest",
    "anh_tham_chieu": [ref], "cho": True,
}, timeout=600).json()
```

</TabItem>
<TabItem label="curl (Windows cmd)">

```bat
curl -X POST http://127.0.0.1:5199/v1/images ^

  -H "Content-Type: application/json" ^

```

### Response

```json
{
  "ok": true,
  "id": "a1b2c3d4e5f60718",
  "trang_thai": "xong",
  "prompt": "a golden retriever astronaut on Mars",
  "so_luong": 1,
  "model": "banana2",
  "ty_le": "1:1",
  "upscale": "4K",
  "giay": 32.1,
  "anh": [
    {
      "chi_so": 0,
      "url": "http://127.0.0.1:5199/v1/images/a1b2c3d4e5f60718/file/0",
      "rong": 4096,
      "cao": 4096,
      "upscale": "4K",
      "byte": 123456
    }
  ]
}
```

`trang_thai` can be `cho` (queued), `dang_chay` (running), `xong` (done), `hong` (failed) or `huy` (cancelled). On failure, the response also includes a `loi` field with the reason.

<Aside type="tip">
- Each image takes about 20–40 seconds. When using `cho: true`, set the caller's timeout to **at least 600 seconds**.
- The first request for a model other than the default is slower, because the tool has to prepare accounts for that model.
- If upscaling fails, the tool still returns the original image.
- When calling from another machine on the network, replace `127.0.0.1` with the local IP address of the machine running the tool.
</Aside>

## HTTP status codes

| Code | Meaning |
| --- | --- |
| `200` | Success. |
| `202` | Job accepted. Or `cho: true` but the wait timed out: check again with `GET /v1/images/<id>`. |
| `400` | Invalid request body: missing `prompt`, unknown model, more than 3 reference images… Read the `loi` field. |
| `401` | Missing or wrong API key. |
| `404` | No such path, job or image. |
| `413` | Request body too large (24 MB max). |
| `502` | `cho: true` but the job failed, e.g. the prompt was blocked by Google. |

## Errors when starting the server

| Message | What to do |
| --- | --- |
| Chưa có khoá API (No API key yet) | Click *Tạo khoá mới* first. |
| Cổng … đang bị chương trình khác dùng (Port … is in use by another program) | Choose a different port. Usually caused by having two copies of the tool open. |
| 🔴 Đang chạy nhưng KHÔNG tạo được ảnh (Running but CANNOT generate images) | Read the reason shown next to it. Usually no account is enabled in the **Tài Khoản** (Accounts) tab. |
