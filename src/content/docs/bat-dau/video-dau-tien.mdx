Trang này dẫn bạn đi một vòng ngắn nhất: từ tool vừa cài tới video đầu tiên.

<TutorialVideo id="quick-start" />

<Steps>

1. **Cài tool và đăng nhập bản quyền**.
   Xem [Cài đặt tool](/bat-dau/cai-dat/) và [Đăng nhập bản quyền](/bat-dau/dang-nhap/).

2. **Thêm ít nhất một tài khoản Google**.
   Vào **👤 Tài Khoản → 🎬 Google Flow** → <kbd>🤖 Thêm Tài Khoản Tự Động</kbd>. Chờ cột Trạng thái báo **✅ Hoạt động** và công tắc **Dùng** đang bật.

3. **Chuẩn bị nguồn**: một file phụ đề `.srt`, file âm thanh, video ngắn, hoặc một link YouTube/TikTok.

4. **Mở 🎞️ Phụ đề/âm thanh → Video** → <kbd>Mở dự án đang làm →</kbd>.

5. Bấm <kbd>Chọn file…</kbd> hoặc dán link rồi bấm <kbd>Tải về</kbd>.

6. Chọn **Phong cách** ảnh và **Tỉ lệ ảnh** (ngang cho YouTube, dọc cho TikTok). Các ô khác để mặc định.

7. Bấm <kbd>Bắt đầu</kbd>. Tool lần lượt: tách sub → phân cảnh → tạo ảnh → xuất video.

8. Bấm <kbd>▶ Xem video</kbd> để xem thành quả.

</Steps>

<Aside type="tip" title="Lần đầu tách sub hơi lâu">
Lần đầu dùng, tool phải tải bộ nghe chữ (~485 MB). Từ lần sau sẽ nhanh hơn nhiều.
</Aside>
